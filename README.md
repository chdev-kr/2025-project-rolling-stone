# 둘 굴러가유 🎯

Three.js를 활용한 3D 바위 피하기 게임입니다. 산에서 굴러오는 바위들을 클릭하여 파괴하고 점수를 획득하는 게임입니다.

![화면 기록 2025-09-21 오후 2 53 43](https://github.com/user-attachments/assets/12edd2dc-d908-4a81-8174-63c3677084cc)


## 🎮 게임 소개

플레이어는 산을 배경으로 하여 날아오는 바위들을 마우스로 클릭하여 파괴해야 합니다. 바위를 성공적으로 클릭하면 점수가 증가하고, 바위는 빨간색으로 변한 후 사라집니다. 새로운 바위가 계속해서 생성되어 끊임없는 도전을 제공합니다.

## ✨ 주요 기능

- **3D 환경**: Three.js를 사용한 몰입감 있는 3D 게임 환경
- **실시간 바위 생성**: 무작위 위치에서 지속적으로 바위가 생성됩니다
- **클릭 기반 게임플레이**: 마우스 클릭으로 바위를 파괴
- **점수 시스템**: 바위를 파괴할 때마다 점수 획득 (바위당 10점)
- **시각적 피드백**: 클릭 시 바위 색상 변화
- **커스텀 커서**: 저격용 십자선 커서
- **반응형 디자인**: 브라우저 창 크기에 맞춰 자동 조정

## 🛠 기술 스택

- **Three.js**: 3D 그래픽 렌더링
- **GLTFLoader**: 3D 모델 로딩 (.glb 파일)
- **Raycaster**: 마우스 클릭 감지 및 3D 객체 상호작용
- **ES6 Modules**: 모던 JavaScript 모듈 시스템
- **HTML5 Canvas**: 3D 렌더링을 위한 캔버스

## 🚀 실행 방법

1. **프로젝트 클론 또는 다운로드**

   ```bash
   git clone [repository-url]
   cd 2025-threejs
   ```

2. **로컬 서버 실행**

   - Live Server 확장프로그램 사용 (VS Code)
   - 또는 Python 서버: `python -m http.server 8000`
   - 또는 Node.js 서버: `npx serve .`

3. **브라우저에서 접속**
   - `http://localhost:8000` 또는 해당 포트로 접속

## 🎯 게임 플레이 방법

1. **시작**: 페이지가 로드되면 게임이 자동으로 시작됩니다
2. **조작**: 마우스로 날아오는 바위들을 클릭하세요
3. **점수**: 바위를 성공적으로 클릭하면 10점을 획득합니다
4. **목표**: 최대한 많은 바위를 파괴하여 높은 점수를 달성하세요

## 🔧 주요 코드 구조

### 메인 게임 로직 (ex03.js)

- **Scene 설정**: 3D 장면, 카메라, 조명 구성
- **모델 로딩**: GLB 형식의 산과 바위 모델 로드
- **바위 생성**: 무작위 위치에서 바위 객체 생성
- **애니메이션**: 바위가 카메라를 향해 이동하는 애니메이션
- **점수 관리**: 클릭 시 점수 증가 및 UI 업데이트

### Raycaster 모듈 (setRaycaster.js)

- **클릭 감지**: 마우스 클릭을 3D 좌표로 변환
- **객체 선택**: 클릭된 3D 객체 식별
- **드래그 방지**: 드래그와 클릭 구분
